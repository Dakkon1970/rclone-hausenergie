# Privacy Policy – rclone Hausenergie

*Last updated: 19 September 2026*

This privacy policy applies to the Google OAuth client **"rclone Hausenergie"**, a private, non-commercial tool used by a single person (the owner) with the open-source program [rclone](https://rclone.org).

## What data is accessed

With the owner's explicit consent, rclone accesses the owner's own Google Drive (scope `https://www.googleapis.com/auth/drive`) in order to synchronise one folder between the owner's own Microsoft OneDrive and the owner's own Google Drive.

## How data is used and stored

- Files are only copied between the owner's own storage locations (OneDrive, Google Drive and the owner's own computer).
- The OAuth access token is stored only locally in the rclone configuration on the owner's own computer.
- No data is sent to, stored on or processed by any server operated by this app. There is no such server.

## Sharing

No data is sold, shared with or disclosed to third parties. No data is used for advertising, analytics or training of AI models.

## Google API Services User Data Policy

The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Contact

Questions: please open an issue in this repository: [github.com/Dakkon1970/rclone-hausenergie](https://github.com/Dakkon1970/rclone-hausenergie/issues)

## Datenschutzerklärung (Kurzfassung, Deutsch)

Die OAuth-App „rclone Hausenergie" ist ein privates, nicht-kommerzielles Werkzeug einer einzelnen Person. Sie greift mit Zustimmung ausschließlich auf das eigene Google Drive des Inhabers zu, um einen Ordner mit dem eigenen OneDrive zu synchronisieren. Zugangsdaten werden nur lokal auf dem eigenen Rechner gespeichert. Es werden keine Daten an Dritte weitergegeben. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
