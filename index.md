# rclone Hausenergie

**rclone Hausenergie** is a private, non-commercial tool used by a single person to synchronise their own files between their own Microsoft OneDrive and their own Google Drive, using the open-source program [rclone](https://rclone.org).

The Google OAuth client "rclone Hausenergie" exists only so that rclone on the owner's own computer can access the owner's own Google Drive. It is not offered to other users.
